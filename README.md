# Week 7 Assignment: My Notes & The Report Builder

- `my_notes.py`: Writes, appends, reads, and counts notes in a text file.
- `my_notes.txt`: Stores the four saved notes generated by `my_notes.py`.
- `report_builder.py`: Reads learner scores from `hubs.csv`, handles missing files, and writes summary stats to `report.txt`.
- `hubs.csv`: Sample dataset containing learner names, hubs, and scores.
- `report.txt`: Generated summary report showing total, passed, failed, and average score.

If you change `"a"` to `"w"` in Question 1, Python overwrites the existing file instead of appending to it, so the first three notes get erased and only `"I added this later\n"` remains.
